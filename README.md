# 조하원 포트폴리오

현업의 문제를 AI 도구로 해결하는 엔지니어, 조하원의 포트폴리오 사이트입니다.

**사이트:** https://wonby1n.github.io/hawon-portfolio/

## 구성

| 페이지 | 내용 |
|---|---|
| [메인](https://wonby1n.github.io/hawon-portfolio/) | 소개, 숫자로 보는 경력, 다루는 기술, 걸어온 길 |
| [코드 리뷰 봇](https://wonby1n.github.io/hawon-portfolio/p-review-bot.html) | 교육생 Merge Request를 AI Agent가 먼저 리뷰하는 n8n 자동화 (20개 팀·120명, 누적 1,000건 이상) |
| [교보재 신청 통합 플랫폼](https://wonby1n.github.io/hawon-portfolio/p-ssakit.html) | 엑셀로 받던 교육용 기자재 신청을 하나로 모은 서비스, FastAPI RAG·Blue/Green 배포 |
| [GluCoach](https://wonby1n.github.io/hawon-portfolio/p-glucoach.html) | 혈당 그래프 화면 요청을 행동 코칭 AI Agent로 키운 기업 연계 프로젝트 (최우수상) |
| [CARe](https://wonby1n.github.io/hawon-portfolio/p-care.html) | AI 신원 인증과 블록체인 계약으로 만든 외국인 렌터카 플랫폼 (우수상) |
| [수상](https://wonby1n.github.io/hawon-portfolio/p-awards.html) | 삼성 청년 SW·AI 아카데미(SSAFY) 14기 팀 프로젝트 4건 수상 |

각 프로젝트 페이지는 "왜 만들었나 → 제가 한 일 → 문제를 다시 본 순간들" 순서로 정리했습니다.

## 만든 방식

- 별도 빌드 없이 HTML·CSS만으로 만든 정적 사이트입니다.
- GitHub Pages로 배포합니다 (`main` 브랜치 루트).
- 비공개 저장소에서 운영 중인 프로젝트는 설정 파일과 코드 일부만 발췌해 실었습니다.
